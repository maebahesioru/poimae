# 評価 — 実測値とその限界

このページは `make eval` の出力（[`eval/CONFUSION.md`](../eval/CONFUSION.md) /
[`eval/report-test.json`](../eval/report-test.json)）をそのまま載せたものです。
**数字を良く見せるための加工はしていません。** 苦手なクラスも、除外した件数も、
そのまま出しています。

- 測定日: 2026-10-20
- 環境: Linux / Python 3.14.8 / opencv-python-headless 5.0.0.93 / `OMP_NUM_THREADS=2` / CPU のみ（GPU 未使用）
- 再現: `make eval`（合成画像を作り直してから測ります）

## 1. 何を測ったか

測っているのは**2つ**で、混ぜないようにしています。

| 測ったもの | 意味 |
| --- | --- |
| **材質分類（material_*）** | 写真 → 10種類の材質のどれか。このアプリの分類器そのものの精度 |
| **配管（pipelines.*）** | 写真 → 材質語 → 自治体の辞典 → 区分。アプリ全体の流れが通るか |

**どちらも「実世界の分別の正解率」ではありません。** 合成画像で測った数値です。

## 2. データ

`tools/synth.py` が生成した合成画像 120枚（10クラス × 12枚）。

- 背景4種（白い机・木目・暗い布・新聞紙）、影、ノイズ、ぼかしをランダムに付加
- 奇数番目のサンプルには**妨害物**（別の小物）を写り込ませる
- `split` で **dev 60枚 / test 60枚** に分割

**dev はルール表の閾値を決めるのに使い、test は測定だけに使っています。**
test を見て閾値をいじったことはありません（`classifier.py` の docstring にも明記）。

> 合成画像は**写真ではありません**。プログラムで描いた見本です。
> 実写真での精度は**未測定**です（[限界](#5-限界)）。

## 3. 材質分類の結果（test 60枚）

| 指標 | 実測値 |
| --- | ---: |
| top-1 正解率 | **65.0%** |
| top-3 再現率 | 88.3% |
| 基準線（常に最頻クラス「ペットボトル」と答える） | 10.0% |
| 背景がきれい（30枚） | 63.3% |
| 妨害物あり（30枚） | 66.7% |

妨害物がある方がわずかに高いのは、**妨害物が偶然 foreground の切り出しを助けた**ためで、
有意な差ではありません（30枚ずつなので誤差が大きい）。

参考: dev 60枚では top-1 **80.0%** / top-3 95.0%。test との差は、
閾値を dev に合わせた分の**楽観バイアス**です。**報告すべきは test の 65.0%** です。

## 4. 配管の結果（写真 → 材質語 → 辞典）

材質語から辞典を引いたとき、**辞典が確信をもって答えられた枚だけ**を採点しています。
（`confident` でない＝候補が複数、は採点から外し、その数を「除外した材質」として出しています。
除外が多いほど採点枚数が減り、**数字が良く見える**ので、必ず枚数と併記します。）

| 自治体 | 採点枚数 | 正解率 | 基準線（最頻の区分だけ答える） | 採点から外れた材質 |
| --- | ---: | ---: | ---: | --- |
| 広島市（公式） | 12 / 60 | 58.3% | 50.0% | ペットボトル・金属缶・ガラスびん・紙・段ボール・プラ容器・生ごみ・電池（8種） |
| 札幌市（公式） | 24 / 60 | 50.0% | 25.0% | 金属缶・ガラスびん・紙・段ボール・プラ容器・生ごみ（6種） |
| サンプル市（ダミー） | 60 / 60 | 71.7% | 30.0% | なし |

ここから分かる、正直な結論:

1. **サンプル市（ダミー）でしか全60枚を採点できていません。** 実在の2市は、
   同じ材質語が複数の品目に分かれる（例:「電池」→ 乾電池・ボタン電池・充電池）ため
   `confident` にならず、採点対象が減ります。**これは分類器の弱さではなく、
   「材質語だけでは品目が決まらない」という現実の反映**です。
2. 広島市の 58.3%（12枚）は基準線 50.0% とほとんど差がありません。**12枚では何も言えません。**
3. 札幌市の 50.0%（24枚）は基準線 25.0% の2倍ですが、これも 24枚の話です。
4. したがって、この表を「実用的な精度」として読むべきではありません。
   **読むべきは「配管が端から端まで通っている」ことと「どこで人に渡しているか」**です。

## 5. 限界

- **実写真で測っていません。** 実写真を集めてラベル付けする作業は今回の範囲外です。
  手元の写真で試すと、合成画像より `unknown` が増えると予想されます（未確認）。
- **クラス数が10**で、日本の分別区分（数十〜数百）に対して粗すぎます。
  材質から品目を1つに決めることは原理的にできません。
- **1枚に1物体**を前提にしています。複数写った写真では最大のブロブだけを見ます。
- 学習モデルではないので、**学習データの偏りという問題は無い**代わりに、
  未知の材質（例: 複合素材、汚れのひどい容器）に弱い。
- 閾値は合成画像の中央値で決めており、**実写真に対する最適値ではありません**。

## 7. 都市間の差（データ側の実測）

分類器とは別に、**データそのもの**から測った数字です。

| 項目 | 実測値 |
| --- | ---: |
| 両市に同名で存在する品目 | 148 |
| 区分を比較できた品目（両市に `generic` がある） | 114 |
| うち区分が同じ | 84 |
| うち区分が違う | **30（26.3%）** |
| 同名だが比較できない（片方に共通語彙が無い） | 34 |
| 注記が「条件つき」の型に当てはまった件数（広島市・618品目） | 130 |
| 同（札幌市・1019品目） | 152 |

区分が違った例（各市の公式ページの記載どおり）:

| 品目 | 広島市 | 札幌市 |
| --- | --- | --- |
| カイロ 使い捨て | 不燃ごみ | 燃やせるごみ |
| クレヨン | 不燃ごみ | 燃やせるごみ |
| サンダル | その他プラ | 燃やせるごみ |
| プリンター | 大型ごみ | 燃やせないごみ |
| キーボード パソコン用 | 大型ごみ | 燃やせないごみ |
| 蛍光管 | 有害ごみ | 燃やせないごみ |

`プリンター` は札幌市の辞典では「プリンタ」、`キーボード` は「キーボード パソコン用」として
載っています。この表は**完全一致した品目名**だけを突き合わせた結果です。

注記の件数は「条件の型（大きさ・汚れ・中身・分解など）に当てはまった回数」で、
1品目が複数の型に当てはまれば複数回数えます。

再現: `make run` した状態で
`curl -s 'http://127.0.0.1:8765/api/ambiguity' | .venv/bin/python -m json.tool`。
